# Banque de sons de Résonaé

Sons libres utilisés par l'application Résonaé (Jérôme Cannet). Les fichiers sont téléchargés par l'application ; les auteurs et licences de chaque son sont dans `banque/banque.json`.

Licences : CC0 (163 sons), Domaine public (30 sons), CC BY 4.0 (9 sons), CC BY (5 sons), CC BY 3.0 (3 sons) : auteurs et liens cités dans `banque/banque.json`. Les 21 bols des centres énergétiques viennent de Freesound (via le jeu de données LAION sur Hugging Face) ; chacun est transposé à la fréquence planétaire de son centre (Cousto), la transposition appliquée est notée dans `src`.
