# Banque de sons de Résonaé

Sons libres utilisés par l'application Résonaé (Jérôme Cannet). Les fichiers sont téléchargés par l'application (Réglages › Modules, ou depuis Créer son ambiance) ; les auteurs, licences et liens de chaque son sont dans `banque/banque.json`.

## Licences (260 sons)

- CC0 : 180 sons
- CC BY 4.0 : 40 sons
- Domaine public : 30 sons
- CC BY 3.0 : 6 sons
- CC BY : 4 sons

Les sons CC BY demandent de citer l'auteur : les auteurs concernés sont ci-dessous et dans Réglages › Crédits de l'application.

## Origines

- Versilian Community Sample Library (VCSL), CC0 : gongs, carillons, claviers percutés, kalimbas, harpes, percussions.
- Freesound (via le jeu de données LAION sur Hugging Face, licences commerciales) : bols des centres énergétiques, gongs, tingshas, cymbalettes, didgeridoos, cordes, tambours, orages, sons de nature. Chaque son est normalisé (mono, Opus) ; pour les bols des centres, la transposition appliquée à la fréquence de son centre (Cousto) est notée dans `src`.
- Sons calculés par Résonaé : bruits blanc, rose, brun, pulsations.

Dossiers : `banque/` (sons), `sinus-sons/` et `whisper-small/` (modules téléchargés par l'application).
